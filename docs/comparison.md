# The ports side by side

One row per aspect of "a simple CLI app"; one column per port. Filled in as
each port lands. Each port's README has the long version under **Anatomy**.

| Aspect | Rust | C# | Java | F# | Clojure |
|---|---|---|---|---|---|
| Project file | [`Cargo.toml`](../rust/Cargo.toml); OS-only deps via `[target.'cfg(windows)'.dependencies]` | [`Whereami.csproj`](../csharp/src/Whereami/Whereami.csproj) + [`.slnx`](../csharp/Whereami.slnx); two target frameworks, `-windows10.0.19041.0` adds WinRT; SDK pinned in `global.json` | [`settings.gradle.kts`](../java/settings.gradle.kts) + two `build.gradle.kts` (`java-library` + `application`); versions in `libs.versions.toml`; Gradle pinned by the committed wrapper | [`Whereami.fsproj`](../fsharp/src/Whereami/Whereami.fsproj): same target frameworks as C#, plus an ordered `<Compile>` list (each file sees only the ones above it) | [`deps.edn`](../clojure/deps.edn): data; deps incl. the Java `platform.jar` via `:local/root`; aliases `:test` and `:build`; [`build.clj`](../clojure/build.clj) only for the uberjar |
| Entry point | [`main.rs`](../rust/src/main.rs): parse → `app::run` → print → `process::exit` | [`Program.cs`](../csharp/src/Whereami/Program.cs): top-level statements, `switch` on `Parsed`, `return` = exit code | [`Main.java`](../java/app/src/main/java/whereami/cli/Main.java): `System.exit(commandLine(…).execute(args))` | [`Program.fs`](../fsharp/src/Whereami/Program.fs): `[<EntryPoint>] let main argv`, `match` on `Parsed`, return value = exit code | [`main.clj`](../clojure/src/whereami/main.clj): `-main` with `(:gen-class)`, UTF-8 writers, explicit `System/exit` |
| Arg parsing | `clap` derive: a struct *is* the CLI; custom `value_parser`; extra rules via `Command::error` (exit 2) | `System.CommandLine`: `Option<T>`/`Argument<T>` objects on a `RootCommand`; own exit-2 handling; response files off | picocli annotations on fields; `@ArgGroup(exclusive)` for `--mock`/`--at`; extra rules throw `ParameterException` (exit 2); `@file` off | Argu: a discriminated union *is* the CLI; `[<HelpFlags>]` for `-h`; leading-dash address words rejected by hand | tools.cli option vectors → `parse-opts` result map; checks are one `cond`; values conformed with `clojure.spec` |
| JSON | `serde` `#[derive(Serialize)]` + `serde_json::to_string` | `System.Text.Json` with `SnakeCaseLower` naming + relaxed encoder | Jackson 3 on a private record, `SNAKE_CASE` naming | `System.Text.Json`, same options as C#; F# records and `option` natively (the record must be public) | data.json `write-str` with `:key-fn` and `:escape-unicode false`; an `array-map` keeps key order |
| Per-OS selection | `#[cfg(target_os = …)]`: compile time, other OSes' code not built | `#if WINDOWS` (compile time) + `OperatingSystem.IsWindows()` (run time) | run time only: `os.name` in `Platforms.nativePlatform()`; every backend compiled everywhere, natives loaded lazily | same as C#: `#if WINDOWS` + `OperatingSystem.IsWindows()` | none of its own: `(Platforms/nativePlatform)` from the Java layer |
| Windows binding | `windows` crate (Microsoft-generated WinRT projection), feature `Devices_Geolocation` | built-in WinRT projection: `new Geolocator { … }` | **by hand**: FFM downcalls into `combase.dll`, COM vtable slots, explicit `Release` | same projection as C#: `Geolocator(DesiredAccuracy = …)` | the Java port's `WindowsPlatform`, called through interop (`(.getLocation p …)`) |
| Linux binding | `zbus` 5 blocking API; `#[zbus::proxy(..., gen_async = false)]` traits generate typed proxies for GeoClue2; errors mapped by D-Bus name | — (planned) | `dbus-java` 5 (pure Java, native-unixsocket transport); interfaces extending `DBusInterface` are proxied, `LocationUpdated` is a `DBusSignal` class; errors mapped by the exception class dbus-java builds from the D-Bus name | — (planned) | the Java port's `LinuxPlatform`, through interop; deps.edn lists dbus-java |
| Async wait | `IAsyncOperation::join()` blocks; bounded by a worker thread + `mpsc::recv_timeout` | `await op.AsTask(ct)`; `CancellationTokenSource` + `WaitAsync(timeout)` | poll `IAsyncInfo.Status` every 50 ms; whole request on one daemon platform thread + `CompletableFuture.get(timeout)` | `task { let! … }`; one `CancellationTokenSource` + one `WaitAsync` for the whole request | whole request in one `future` (a platform thread); `(deref f ms ::timeout)` |
| Error handling | `Result` + `?`; HRESULT → `LocationError` in `map_hresult` | exceptions: `LocationException`; WinRT failures → `MapException` with exception filters | checked `LocationException` (`throws` in signatures); `HRESULT` → `WinRtException` → `HResults.toError` | `Result<_, LocationError>` values; projection exceptions caught once and mapped by `mapException` | data: Java's `LocationException` becomes `{:error :permission-denied}` at the boundary |
| Testability | `app::run(&Request, &dyn Platform)` + a `Fake` platform | `App.RunAsync(Request, IPlatform, TimeSpan)` + a `Fake : IPlatform` (xUnit, separate project) | `App.run(Request, Platform, Duration)` + a `Fake`; COM calls tested against a fake vtable of upcall stubs | `App.run` + fakes as record copies: `{ Platform.unsupported with GetLocation = … }` | `app/run` + `reify Platform` fakes; `s/fdef` + `stest/instrument`; a test.check property |
